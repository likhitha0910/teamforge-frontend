# TeamForge Frontend (HTML, CSS, JavaScript)
Plain HTML5 + CSS3 + JavaScript (Fetch API). No frameworks.

1. Start the backend first (http://localhost:8080).
2. Open this folder in VS Code, right-click `index.html` -> **Open with Live Server**
   (install the "Live Server" extension), or just double-click `index.html`.
3. The backend address is set at the top of `js/app.js` (`API_BASE`).
